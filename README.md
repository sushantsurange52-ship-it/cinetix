# CineTix — Modern Event & Movie Booking Platform

A modern, animated e-ticketing single-page application built with React, Vite, Tailwind CSS, and Framer Motion.

## Features
- **Landing Page**: Animated gradient mesh & particle background, multi-field search bar (event/city/category), and trending events carousel.
- **Events Listing**: Real-time filtering by category, price slider, metro area, search query, and sorting options.
- **Event Details**: Cinematic banner, date & showtime selector, animated tabs (Synopsis, Venue & Acoustics, Verified Reviews), and sticky booking bar.
- **Interactive Seat Map**: Curved cinema screen with 3D perspective glow, tiered seating (Standard, Prime, VIP Recliner), live hover tooltips, and seat selection state.
- **Multi-Step Checkout**: Animated step progress bar (Attendee Contact Info → Payment Method with Demo Autofill → Final Order Review).
- **Ticket Confirmation**: Confetti celebration, 3D holographic ticket reveal with perforated stub, QR admission code, printable PDF download, and digital wallet links.
- **Glassmorphic Dark Theme**: Electric purple & orange vibrant accents, smooth Framer Motion page transitions, and responsive mobile-first design.
